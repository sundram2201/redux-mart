# Redux Mart

Redux Mart is an e-commerce project developed using the MERN stack. This application showcases my skills in building a full-stack application with advanced features like user authentication, product management, cart functionality, and payment processing.

## Features

- **User Authentication**: Secure user registration and login with JWT.
- **Product List**: Browse through a catalog of products.
- **Add to Cart**: Add products to a shopping cart for later purchase.
- **Add to Favorite**: Mark products as favorites for quick access.
- **User Profile**: Manage user account details and view order history.
- **Cart List**: View and manage items in the shopping cart.
- **Product View**: Detailed view of individual products.
- **Payment Gateway**: Integrated Stripe payment processing for secure transactions.

## Tech Stack

### Frontend

- **React.js**: Library for building user interfaces.
- **Redux Toolkit**: State management for complex applications.
- **Material-UI**: UI component library for React.
- **Stripe**: Payment processing.
- **Axios**: HTTP client for making requests.
- **Formik**: Forms library for React.
- **Framer Motion**: Animation library for React.
- **React Router**: Routing library for React applications.

### Backend

- **Express.js**: Web framework for Node.js.
- **MongoDB**: NoSQL database.
- **Mongoose**: MongoDB object modeling tool.
- **JWT**: JSON Web Tokens for user authentication.
- **Stripe**: Payment processing.
